# Vedant Poman — Personal Portfolio

Minimalist modern portfolio built with React, showcasing projects in AI/ML, Computer Vision, and Full-Stack Engineering.

## Quick Start

To run the project locally from this root directory:

```bash
npm run dev
# or
npm start
```

This will run the portfolio app in `personal-portfolio` on `http://localhost:3000`.

To create a production build:

```bash
npm run build
```
